# Ably (ably)

Ably is a realtime messaging platform offering pub/sub, presence, push notifications, chat, LiveSync, and integrations over WebSocket and HTTP. Ably publishes its OpenAPI specifications publicly via the ably/open-specs GitHub repository, with separate specs for the Platform API and the Control API.

**URL:** [Visit APIs.json URL](https://raw.githubusercontent.com/api-evangelist/ably/refs/heads/main/apis.yml)

## APIs
- **Ably Platform API** (`https://rest.ably.io` / `wss://realtime.ably.io`) - Pub/Sub messaging
- **Ably Control API** (`https://control.ably.net/v1`) - Account, app, and key management
